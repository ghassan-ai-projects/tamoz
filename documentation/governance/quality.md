# The quality bar

Every change to Tamoz must pass the quality gates before it merges. The gates
are not aspirational: they are automated, and they fail closed.

## The everyday gate

```sh
rbenv exec bundle exec rake ci
```

`rake ci` runs, in order:

- **design validation** — the authoritative design package (`docs/design-v0.1`)
  must stay consistent;
- **syntax pass** — `ruby -wc` over every source file;
- **fast tests** — the behavior test set, excluding the slow serial tail;
- **proto drift check** — the committed gRPC stubs must match a fresh codegen;
- **architecture check** — Enola against `mcp-arch.yaml`.

`ci` finishes by warning that it skipped the slow set. Changes touching
durability, MCP, packaging, or committed evidence artifacts must run the
complete gate instead:

```sh
rbenv exec bundle exec rake ci_full
```

## The ratchets

The quality ratchets compare every run against committed baselines and fail
rather than let them grow. They live under `rake quality:*`:

- **Reek** — no new smell in any production file versus the committed baseline
  (`docs/code-quality-baseline.json`).
- **SimpleCov** — the line and branch coverage floor must not decrease.
- **Enola architecture check** — no cycles, no layer violations, no unexplained
  spillover, against `mcp-arch.yaml`.
- **Both-locales gate** — the gates must pass under a UTF-8 locale and under
  `LC_ALL=C LANG=C`, with identical assertion totals in both.

## The governing documents

Two documents define how this bar is applied:

- [docs/CODING_STANDARD.md](../../docs/CODING_STANDARD.md) — the repository's
  Ruby/Rails coding contract; every code change follows it.
- [docs/QUALITY_PROGRAM.md](../../docs/QUALITY_PROGRAM.md) — the charter for the
  quality program that owns the ratchets and their baselines.

## Evidence, not prose

Every release claim in Tamoz is machine evidence. The committed manifests
(`docs/requirements-manifest.json` and `docs/requirements-audit.json`) are
regenerated by running the named tests, and a row is `pass` only because its
test executed and passed. Prose never substitutes for a gate.
