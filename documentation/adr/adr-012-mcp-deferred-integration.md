# ADR-012 — MCP is a deferred integration strategy (RETIRED)

**Status:** Retired — superseded by [ADR-029](./adr-029-mcp-is-native-at-the-edge-and-uses-the-official-ruby-sdk.md).
**Date:** 2026-07-30 (superseded 2026-07-30; MCP has since shipped)

This decision is no longer in force. It treated MCP as deferred post-v0.1 work. MCP is now
native at the edge via the official Ruby SDK and has shipped (`tamoz-mcp`,
`tamoz-mcp-websearch`).

- **What replaced it:** [ADR-029 — MCP is native at the edge and uses the official Ruby SDK](./adr-029-mcp-is-native-at-the-edge-and-uses-the-official-ruby-sdk.md).
- **Why it died:** [`RETIRED.md`](./RETIRED.md).
