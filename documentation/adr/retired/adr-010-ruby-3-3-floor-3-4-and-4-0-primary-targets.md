# ADR-010 — Ruby 3.3 floor; 3.4 and 4.0 primary targets (RETIRED)

**Status:** Retired 2026-10-02 — withdrawn
**Date:** 2026-07-30

This decision is no longer in force. It set MRI 3.3 as the minimum, pinned development and CI to
3.3.11, and named 3.4 and 4.0 as untested future targets. It also deferred JRuby support.

The owner withdrew this record because a separate ADR for Ruby version policy is unnecessary.
The gem specifications, `.ruby-version` and CI configuration remain unchanged. Retirement does
not establish support for another Ruby version.
