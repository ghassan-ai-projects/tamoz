# ADR-002 — Four v0.1 runtime gems (RETIRED)

**Status:** Retired 2026-08-26 — superseded by [ADR-052](../adr-052-a-gem-owns-one-dependency-boundary-and-is-reached-only-through-its-facade.md)
**Date:** 2026-07-30

This decision is no longer in force. It said v0.1 would ship four runtime gems (`tamoz-core`,
`tamoz-graph`, `tamoz-sqlite`, `tamoz-agent`). `tamoz-agent` was decomposed into focused gems, and
ADR-052 now states when a concern becomes a gem.
