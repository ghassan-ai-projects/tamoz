- principle: 2 (hard ceiling 30) + 5 step-down; §4 one responsibility
- evidence: def spans 259–305, ~35 code lines; one method does three jobs: shape-enforce

  synthetic profile document (280–296), then run the validator sequence. The other two
  loaders (`load`, `load_document`) already read as short pipelines; this is the outlier.

  refusal point for tampered checkpoints) and `build_synthetic_document(hash)` (280–296;
  keeps the existing local name `synthetic`). `from_authority` drops to ~12 lines: type
  refusal → shape enforcement → build → run validator list → `build_fields`.
- risk: low
- within_file: yes
