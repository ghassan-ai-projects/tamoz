# M0 evidence

M0 is complete only when `bundle exec rake ci` proves:

- the copied design package is internally valid;
- all five gem manifests build under the declared Ruby range;
- runtime package loading does not pull optional packages or `tamoz-evals`;
- the documented public API matches the actual constants and methods;
- case and result schemas reject unknown or malformed fields;
- canonical digests detect modification;
- every referenced evidence file is present, contained, and digest-valid;
- all twelve golden cases verify;
- pass, fail, invalid, infrastructure-failure, and insufficient-evidence results return
  distinct CLI exit codes;
- GitHub CI covers Ruby 3.3, 3.4, and 4.0.

This is an evaluation and packaging milestone. It does not claim graph, persistence, agent,
memory, healing, MCP, scheduling, skill, or physical-world runtime behavior exists yet.

The durable format is specified in [`evaluation-artifacts-v1.md`](evaluation-artifacts-v1.md).
The post-implementation review and resolved findings are recorded in
[`reviews/M0_DEEP_REVIEW.md`](reviews/M0_DEEP_REVIEW.md).
