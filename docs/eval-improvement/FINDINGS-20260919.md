# Findings — issues and design-principle concerns for later fixing (2026-09-19)

Surfaced while building the world-class eval on `eval-improvement`. **None were fixed in tamoz
production code** (owner's rule: the eval shows what should be; fixing or accepting is a separate,
deliberate choice). Each open item is pinned by an eval so it stays visible. Two framework
defects *were* fixed, recorded here for provenance. Ordered most-decision-worthy first.

## Open — design-principle gaps (owner to fix or accept)

### O1. The recommendation layer has no evidence-fitness gate (0/8 cells)
**Where:** `gems/tamoz-stream/lib/tamoz/stream/decision_builder.rb`; eval
`test/thermal_evidence_gate_eval_test.rb`.
**What:** `DecisionBuilder` governs a proposal's *risk* (from the catalog, never the model) but
never its *evidence sufficiency*. `box_temp_quality` and the raw situation facts are read nowhere
in production code. A naive model that proposes `request_bounded_cooling` on unusable evidence
gets an R2 actuation recommendation on every cell: unusable quality (0/4), stale-by-age (0/2),
out-of-range (0/2) — **0/8 enforced**.
**Design question:** should the brain refuse to *recommend* actuation on unfit evidence (defence
in depth), or is evidence-gating solely the dispatcher's job (ADR-038)? The eval is independent
(tamoz-only), so it states only that tamoz's own layer provides no such defence; a downstream
dispatcher may still refuse. Either answer is legitimate — but a green thermal suite must not be
read as if tamoz enforced this (see O5).

### O2. Confidence is inert in the thermal loop
**Where:** `decision_builder.rb` (`watch_preferred?`, `watch_confidence_floor`);
`decision_node_builder.rb:46` (`raw_confidence`); `test/support/domain_loader.rb#document`.
**What:** The thermal envelope runs with `watch_confidence_floor == 0`, and the domain document
never sets `raw_confidence` (so the decision sees confidence `0.0` regardless of the diagnosis
probabilities). Consequence: an unknown / zero-confidence diagnosis still yields R2 cooling — the
`confidence → watch` demotion (the mechanism that would express "unknown-outcome-stops-work") is
present in code but **unexercised and unenforced** on the physical path. Even the
"confident-excursion" decision test actually runs at confidence 0.0.
**Direction:** decide whether the physical loop should set a non-zero confidence floor and
populate `raw_confidence`; if so, an eval for "unknown outcome → abstain" becomes encodable (it
needs those two knobs exposed through the episode harness).

### O3. The promotion holdout bar is "no regression", not "improvement"
**Where:** `gems/tamoz-agent-improvement/lib/tamoz/agent/improvement/evaluation_report.rb#decide`;
eval `test/heuristic_promotion_controls_test.rb` (`test_recorded_neutral_holdout_still_promotes`).
**What:** `decide` promotes when development strictly improves AND the holdout does not *regress*.
A candidate that improves development but is exactly **neutral** on the holdout (margin 0) still
promotes. ADR-023's spirit ("promoted only on a distinct holdout") may intend a positive holdout
margin. Pinned so any tightening is deliberate.

### O4. Thermal discrimination is concentrated in one scenario family
**Where:** `test/support/thermal_tournament.rb`, `test/fixtures/domains/thermal-lab.json`; evals
`test/thermal_tournament_test.rb`, `test/thermal_tournament_controls_test.rb`.
**What:** After balancing (G2), all four acting cells sit in `thermal-clear`; `thermal-conflict`
is all-abstain. The paired comparison's cluster bootstrap therefore draws its acting signal from
one family, so its CI lower bound is soft (the tests assert a positive point estimate, not a CI
floor). An acting cell in `thermal-conflict` would contradict that family's semantics, so
broadening needs *new* conflict-family scenarios, not more cells.

### O6. Missing capability: active investigation when data is insufficient (owner-requested)
**Where:** `gems/tamoz-stream/lib/tamoz/stream/evidence_client.rb` (bounded read-only tool client),
`decision_builder.rb` (`request_evidence` R0), `episode_nodes.rb` (single-pass DIAGNOSE;
`RECONSIDER` never calls the model); plan `measurement-plans/16-active-investigation.md`.
**What:** the primitives exist (evidence client, `request_evidence` intent) but there is no
investigate-then-decide loop: on insufficient data the governed outcome is abstain, never
"recognize the gap → request the specific datum / query evidence tools → re-analyse → decide."
**Direction:** build the loop (bounded, read-only, capability-scoped, never fabricating the missing
datum or actuating during investigation); the eval in plan 16 specifies it and will show the gap
(pending) until built. This is a NEW capability, not a defect.

## Open — coverage limitation (scope statement, not a bug)

### O5. The tamoz physical eval measures recommendation + governance, not dispatch-time safety
**What:** The thermal suites exercise tamoz's recommendation path with a fixture model. They
measure model judgment and tamoz's governance guarantees. The dispatch-time physical-safety gate
("fail closed on weak evidence before actuating", M0 `physical-evidence-gate`) lives at the
dispatch boundary, deliberately outside tamoz (ADR-038), and is **not** exercised by any tamoz
eval — `m0.physical-evidence-gate` is a declarative contract case, not a live gate. A bench run
(P3) tests the dispatcher; it does not need the brain. Keep the two claims separate.

## Closed this session — framework defects (provenance)

### C1. Dead safety gate: `c3.unknown_reported_as_terminal` was tautological — FIXED (477244b)
It selected outbox rows whose status was already `unknown`, then asked whether any had status
`succeeded`/`failed` — impossible, so the gate could never fire. Now fails when an unknown-status
row carries a receipt it never earned. All 27 comms hard-zero gates now demonstrably trip.

### C2. Thermal baseline degenerated into the adversary — FIXED (d37dbc4)
Balancing the corpus flipped the majority truth-code to the alarm code, and `baseline_cells`
decided act/abstain by `primary_code == ALARM_CODE`, so the fixed-threshold baseline began acting
on every cell (it became the adversary), inflating the supervisor's margin as a corpus artifact.
Fixed: the baseline's decision is now the threshold crossing itself, independent of the classifier
fallback. (Caught by sub-agent review, not by the author.)
