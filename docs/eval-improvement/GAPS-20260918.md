# Gap map — what the instrument cannot yet find, before we spend a model call

Goal (this pass): make every eval surface able to **reveal a weakness**, then run the live model
once against a complete instrument. Not "score what we have" — find what we don't.

The rule from the coding slice holds for every surface: **nothing is measured until the grader is
shown to discriminate.** [`QUALITY_BAR.md`](QUALITY_BAR.md) bar 7. The coding slice now passes
that bar (five controls through the real judge, [`agenteval/README.md`](../../agenteval/README.md)).
The other three surfaces do not — and that, not a low score, is why a live run today would not
tell us where Tamoz is weak.

This map corrects [`PLAN.md`](PLAN.md) against the code: the breadth and physical harnesses are
far more built than the plan's prose implies. The remaining **offline** work is smaller and
sharper than C/P suggested.

## Offline build order (all free; no model call)

1. **G1 — breadth/comms control suite (highest leverage).** Mirror agenteval's V1: `null` /
   `cheap` / `oracle` / `adversary` driven through the *real* oracles.
   - **Chat study (C1–C9): DONE** — [`test/benchmark_comms_controls_test.rb`](../../test/benchmark_comms_controls_test.rb)
     drives the real `OpenclawCommsOracles` (pure functions of the durable-fact snapshot) with
     four controls derived from a real passing snapshot. `oracle` passes every scenario;
     `null`/`cheap` fail every scenario; `adversary` trips **all 27** hard-zero gates (the 27th,
     `c3.unknown_reported_as_terminal`, after the fix below).
     - **Finding, FIXED:** `c3.unknown_reported_as_terminal` was tautological — it selected
       outbox rows whose `status == 'unknown'`, then asked whether any of *those* had status
       `succeeded/failed`, impossible by construction, so the gate could never fire. Now it
       fails when an unknown-status row carries a receipt (a receipt is the terminal proof; an
       ambiguous delivery has none). All 27 hard-zero gates now demonstrably trip.
   - **Intelligence mission surface (`OPENCLAW_MISSIONS`): DONE** —
     [`test/openclaw_mission_controls_test.rb`](../../test/openclaw_mission_controls_test.rb)
     drives the real `OpenclawMissionRunner` + `Readiness` over the committed 9-mission catalog
     with the four control executors: `oracle` reaches `ready` with no mission fault; `null`
     and `cheap` are `blocked` on every mission; `adversary` is `failed` on every mission with
     the tripped hard-zero recorded as the cause. (This proves the *gate* discriminates given
     executor evidence; whether the executor faithfully derives that evidence from real agent
     behaviour still needs the live run.)
   - **`controls_passed` gate: DONE** — `rake benchmark:prove` runs the three control suites as
     one offline gate (the analogue of `agenteval:prove`). `--controls-passed` on a publishing
     run is documented as that gate's output, not an operator's assertion
     ([`openclaw-intelligence-study/README.md`](../../documentation/benchmark/openclaw-intelligence-study/README.md)).
     A follow-up could make the run script shell out to the gate and fail closed, rather than
     trust the flag; deferred because it touches the live/paid path and is not offline-verifiable.
2. **G4 — control the thermal tournament: DONE.**
   [`test/thermal_tournament_controls_test.rb`](../../test/thermal_tournament_controls_test.rb)
   adds a `null` supervisor (always abstains) and an `adversary` supervisor (acts on every
   cell), and proves the governed supervisor beats both — decisively on the safety-weighted
   regret metric (supervisor 0 < adversary < null), narrowly on plain accuracy. The scoring
   discriminates judgment from both trivial strategies.
3. **G2 — size the thermal corpus: DONE.** The corpus was 8 trials, **7 abstain / 1 act**, so a
   do-nothing `null` supervisor scored 7/8 on plain accuracy and accuracy barely separated it
   from the governed one. Added three clear-excursion acting cells (`sustained-rise-modest`,
   `-warm`, `-sharp`), each verified to govern to R2 through the real graph. The corpus is now
   11 cells (4 act / 7 abstain): null accuracy drops to 0.64 vs the supervisor's 1.0 (margin
   0.36, was 0.125), so accuracy now discriminates alongside the regret metric. Coordinated
   updates to `thermal_tournament_test` (acting list, baseline abstention-quality 7/11) and the
   G2 guard in `thermal_tournament_controls_test`.
   - **Fix surfaced by review:** balancing the corpus flipped the majority truth-code to the
     alarm code, and `baseline_cells` had been deciding act/abstain by `primary_code ==
     ALARM_CODE` — so the fixed-threshold baseline degenerated into "act on everything" (it
     became the adversary), inflating the supervisor's margin as a corpus artifact. Fixed: the
     baseline's act/abstain decision is now the threshold crossing (`box_temp > 6`) itself,
     independent of the classifier's majority fallback. It correctly abstains on the low-temp
     cells again and false-alarms only on the conflict cells — its genuine blind spot.
   - Note: acting cells all sit in `thermal-clear`; an acting cell in `thermal-conflict` would
     contradict that family's semantics, so the paired comparison's discrimination is
     concentrated in one bootstrap cluster (tests assert a positive point estimate, not a CI
     floor). Widening across families would need new conflict-family scenarios, not more cells.
4. **G3 — improvement promotion as a discrimination gate: DONE.**
   [`test/heuristic_promotion_controls_test.rb`](../../test/heuristic_promotion_controls_test.rb)
   proves ADR-023's promotion gate rejects the adversaries it exists to stop, through the real
   `Promotion` + `EvaluationReport` + `Memory::Engine`: an **overfit** candidate (gamed
   development, regresses on the held-out set) is refused; a **forged report** (a candidate
   supplying its own evidence) raises `EvaluatorTamperError`; a **self-promoter** (actor ==
   generator) raises `SelfPromotionError`; an **ungated** activation raises
   `UngatedActivationError`; and a **rollback** restores the prior epoch byte-identically. The
   oracle bundle promotes into live behaviour.
   - **Finding (recorded):** `decide`'s holdout bar is *no regression*, not *improvement* — a
     candidate that improves development but is exactly neutral on the holdout still promotes.
     Pinned by `test_recorded_neutral_holdout_still_promotes` so any tightening is deliberate.
   - The premise "only the unknown-effect guard is evaluated" was outdated: the healing side
     (ADR-028) is already covered by the `self_healing_*` suites and the
     `m0.healing-unknown-effect` contract case. A healing-side control suite mirroring this
     promotion one is a follow-up.
5. **G5 — horizon axis: DONE (offline part).** Task length is now a declared property of every
   agenteval task (`Task#horizon`, default `:short`) and the report states its horizon coverage:
   `horizon.covered` is the classes the corpus exercises and `horizon.gaps` names the classes it
   does not (`medium`, `long`). So every published number is read against "we only measure
   short-horizon tasks" as a visible fact, not an assumption (QUALITY_BAR bar 2, METR's lesson),
   and a blended-across-horizons rate is prevented the way the acting/inaction split is. Guarded
   by a grader test asserting the whole corpus is `short` and the two longer classes stay named
   gaps. The long end itself — a soak-scale task — is inherently a live/hardware measurement
   (the 8-hour physical fault soak, P8), out of scope for an offline pass.

Then, and only then, the single live pass: the paid coding baseline (W2), the noise floor (S3),
and one `real_provider` breadth run — each now against an instrument proven to discriminate, so a
low number reads as a real weakness rather than a grader artifact.
