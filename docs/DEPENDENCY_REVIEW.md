## Provenance

- Every version above is PINNED by `Gemfile.lock`; the lockfile is committed.
- Each Tamoz gemspec requires `rubygems_mfa_required`, so a published gem
  cannot be pushed from an account without multi-factor authentication.
- The clean-clone rehearsal installs offline from the local gem cache, so a
  release candidate is reproducible without a network fetch that could resolve
  differently.
- Tamoz fetches no code at runtime: there is no plugin loader, no gem install
  path, and no skill-install pipeline (see `docs/LIMITATIONS.md`).
