# M2 evidence

M2 implements the deterministic in-memory graph algebra in `tamoz-graph`.

It guarantees:

- canonical compiled definitions and domain-separated definition, activation, attempt, and
  checkpoint identities;
- one frozen state snapshot per super-step and one ordered whole-batch reducer call per
  affected channel;
- byte-identical inline and threaded checkpoint histories independent of completion timing;
- declared static, branch, additive, and keyed `Send` routing with PULL fan-in de-duplication;
- worker-local positional interrupts, restart from line one, retained successful siblings,
  and explicit failure retry;
- immutable append-only history, strict per-namespace sequences, reducer-mediated edits, and
  historical forks;
- invocation-mode subgraphs sharing one explicitly inherited checkpointer under deterministic
  namespaces;
- bounded execution streams whose early closure cooperatively cancels work and prevents late
  graph-state commits;
- configured and hard ceilings for steps, tasks, pending bytes, history reads, retained
  namespaces, retained checkpoints, stream buffers, codec values, and cancellation callbacks.

M2 does not claim process-crash recovery, lease fencing, durable request deduplication,
external-effect safety, or multi-process ownership. Those are M3 contracts.

The executable evidence includes an independent barrier reference model, 120 randomized
completion schedules, generated cycles, stop-at-every-event stream tests, parallel nested
subgraphs, multi-interrupt resume, stale-result rejection, package-isolation checks, and all
M0/M1 gates.

The reviewed implementation contract is in `M2_PLAN.md`. Findings and resolutions are
recorded in `reviews/M2_DEEP_REVIEW.md`.
