## Lens: correctness

- **R01 — the `ci` prerequisite list contradicts `docs/QUALITY_PROGRAM_STATE.md`'s documented gate policy.** The state doc says (line 122-123): "`rake ci` now includes the three fast gates (rubocop_gate + reek + architecture) — one command, one gate", and `docs/QUALITY_PROGRAM.md:187-188` (owner-confirmed gate policy) says "`rake ci` (fast gate, ~49s) + `rubocop` + `enola check` is the everyday gate". `Rakefile:444` lists **none** of `quality:rubocop`, `quality:rubocop_gate`, `quality:reek`, `quality:coverage`, `quality:baseline_drift`. - **Source evidence** `script/capture_phase2_receipt:113` — `missing_path = File.join(Dir.tmpdir, "tamoz-phase2-missing-#{Process.pid}.json")`; `:145` builds a `command_result` whose `argv` is `command.map(&:to_s)` (`:45`); `:151` keeps `stdout_b64`/`stderr_b64`/`side_effects` but the `argv` is what carries the path. - **Disposition** Open, minor.

### S01-ADR-01 — `adr_verify.rb`'s fixed ±60-character absence window can invert a true claim
- **Severity** `minor` · **Confidence** `medium` · **Status** `open`
- **Source evidence** `script/adr_verify.rb:18` (`ABSENCE` regex), `:35` — `absent_ctx = ver[[0, at - 60].max...(at + tok.length + 60)] =~ ABSENCE`; `:45-48` — an absent-context citation that *exists* is reported as a problem, and vice versa.
- **Test/contract evidence** `adr:verify` runs only in `ci_full` (`Rakefile:471`); no dedicated test — `not found`.
- **Scanner signal** reading the window arithmetic.
- **Independent judgment** Confirmed as a source property; **medium** because I did not enumerate the ADR corpus for a citation that actually trips it. The window has no sentence boundary, so a sentence mentioning a removal and a live path within 60 characters of the citation flips the expected polarity. The file's own comment (`:16-17`) shows the author already narrowed the phrase list once for exactly this class of false positive.

Preventing contract: the absence decision is scoped to the sentence (`ver.split(/(?<=\.)\s+/)`) rather than a fixed radius.

- **Disposition** Open, minor; may be closed as `info` if the coordinator judges the heuristic adequate for its gate role.

### S01-ADR-02 — the four ADR scripts disagree on how an ADR's state is derived
- **Severity** `minor` · **Confidence** `medium` · **Status** `open`
- **Source evidence** `adr_validate.rb:41-42` (`status =~ /^Retired/i || h1 =~ /\(RETIRED\)/`), `adr_catalog.rb:26-30` (same two clauses, different order), `adr_traceability.rb:27` (**status line only** — the H1 `(RETIRED)` marker is ignored). `adr_validate.rb:59-60` then *requires* a successor reference on any ADR it classifies retired, and `adr_validate.rb:56-57` `failures` if a numbered ADR has no file.
- **Test/contract evidence** No test constructs a divergent ADR — `not found`. They agree on the current corpus (implied by `adr:validate` + `adr_catalog --check` being green in the everyday gate).
- **Scanner signal** the three regex sites.
- **Independent judgment** Latent and **medium** confidence: I verified the three classifiers differ by reading, but I did not mutate an ADR to demonstrate a divergence. The concrete divergence path is an ADR whose H1 carries `(RETIRED)` but whose `**Status:**` line does not start with `Retired`: `catalog.json` calls it retired, `traceability.md` calls it accepted, and `adr_validate` fails the build — so the failure is loud, not silent. That lowers the severity, not the duplication.
- **Five whys** 1. Three artifacts can disagree about one ADR's state. 2. Because each script re-derives state independently. 3. Because they were written at different times against the same prose format. 4. Because no shared parser exists. Preventing contract: one classifier, or one test asserting all three agree over the corpus.
- **Recommendation** Have `adr_traceability.rb:27` and `adr_validate.rb:41` read the state the way `adr_catalog.rb:26-30` already does (both clauses), or add a corpus-wide agreement assertion to `adr_validate`. Prefer the one-line alignment; a shared parser is more machinery than three call sites justify under the repo's "simple solution" convention.
- **Disposition** Open, minor.
