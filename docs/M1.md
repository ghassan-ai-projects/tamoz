# M1 evidence

M1 is complete only when `bundle exec rake ci` proves:

- `tamoz-core` loads with standard library and Zeitwerk only;
- the supported-value boundary is deterministic, immutable, versioned, allowlisted, and
  bounded;
- registered values require an explicit, enforced immutability predicate;
- secrets, cycles, unknown versions, malformed wire values, and excessive inputs fail
  closed;
- Context identity is explicit and isolated, while injected service handles remain owned by
  their callers;
- cancellation subscriptions, work, workers, queues, streams, and namespace history are
  bounded;
- instrumentation cannot execute application code twice, replace its result, or suppress
  its exception;
- stream shutdown wakes blocked producers and distinguishes normal finish from cancellation;
- inline and threaded pools return the same ordered typed-result contract under
  deterministic schedule variation;
- uncooperative work becomes `Stuck` and opens a circuit without asynchronous thread
  termination;
- the installed `tamoz-core` gem runs every M1 primitive without repository load paths;
- four public M1 conformance cases regenerate byte-for-byte and verify;
- the fixed evidence runner rejects a dirty release revision and executes only
  source-controlled test selections inside an OS-enforced network sandbox.

Local verification uses Ruby 3.3.11. The CI definition covers Ruby 3.3, 3.4, and 4.0, but
hosted results are not claimed until the commit is pushed and those jobs pass. On hosts
without a supported OS sandbox, the network-isolated evidence run reports that limitation
instead of claiming denied network access.

This milestone does not implement graph execution, checkpoints, persistence, effects,
models, planning, an agent, memory, healing, MCP, scheduling, skills, streaming input, or
physical-world action.

The reviewed implementation contract is in [`M1_PLAN.md`](M1_PLAN.md). Findings and
resolutions are in [`reviews/M1_DEEP_REVIEW.md`](reviews/M1_DEEP_REVIEW.md).

The final pre-commit local gate passed 101 tests and 1,113 assertions with no failures,
errors, or skips; validated 22 design documents, 55 invariants, and 40 ADRs; and built all
five gems.
