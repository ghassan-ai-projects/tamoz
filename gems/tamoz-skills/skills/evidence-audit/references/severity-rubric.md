# Severity rubric

| Severity | Use when |
|---|---|
| `high` | The criterion is not met in a way that exposes the organisation now: a control is missing, a limit is exceeded, a required approval did not happen. |
| `medium` | The criterion is met only partly, or a weaker control stands in for the required one. |
| `low` | A documentation or wording gap with no evidence of a practical failure. |
| `info` | No exception (`no_exception` is always `info`), or an observation worth recording. |

`insufficient_evidence` takes the severity the exception would have if confirmed.
